AI chatbot using Gemini API, enabling intelligent conversations, file uploads, image analysis, themes, and responsive interactions.
The product is a web-based AI chatbot inspired by Google Gemini, built using HTML, CSS, and JavaScript. It provides users with an interactive interface for communicating with an AI model through the Gemini API.

Key features include context-aware AI conversations, file and image uploads, suggested prompts, real-time response typing effects, chat deletion, response cancellation, and persistent light/dark theme switching. Uploaded images, PDFs, TXT, and CSV files can be attached to queries for context-based responses.

The product focuses on delivering a modern, responsive, Gemini-inspired user experience, with mobile support, animated interactions, clean chat bubbles, and an intuitive prompt interface.

Technically, it integrates directly with Google's Gemini API and maintains conversation history to support ongoing interactions. Users must provide a Gemini API key to activate AI responses.

Overall, it is a beginner-friendly AI chatbot product/prototype that demonstrates AI integration, file-based querying, frontend development, and modern conversational UI design.
